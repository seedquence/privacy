# 🌱 Seedquence – Privacy Policy

Official privacy policy repository for **Seedquence**, an iOS plant-growing game.

## About Seedquence

Seedquence is an iOS game featuring plant cultivation, progress tracking, and global leaderboards.

## Services Used

- Apple Game Center – Global leaderboards
- Apple iCloud – Game progress synchronization
- Local Notifications – Plant care reminders

## Privacy Policy

### 🌍 Available Languages

The privacy policy is available in two languages:

- 🇺🇸 **English (EN)** – Default language
- 🇩🇪 **German (DE)** – Optional language

English is displayed by default. Visitors can switch between English and German using the language selector at the top of the page.
